# 8-Week SQL Challenge — My Solutions

A personal learning log for the **8 Week SQL Challenge** created by Danny Ma and Data With Danny. This repository contains my original SQL attempts, notes, and takeaways. The case studies, questions, and datasets belong to their original publisher; use the official pages below to access them.

> This is an independent study repository and is not affiliated with or endorsed by Data With Danny. I do not reproduce the case study datasets or question text here.

## Challenge plan

| Week | Case study | Main analysis focus |
|---|---|---|
| 1 | [Danny's Diner](Case-Study-1-Danny-s-Diner/) | Joins, aggregation, customer behavior |
| 2 | [Pizza Runner](https://8weeksqlchallenge.com/case-study-2/) | Cleaning messy data, order and runner metrics |
| 3 | [Foodie-Fi](https://8weeksqlchallenge.com/case-study-3/) | Subscription events, plans, churn and cohorts |
| 4 | [Data Bank](https://8weeksqlchallenge.com/case-study-4/) | Customer transactions, balances and growth |
| 5 | [Data Mart](https://8weeksqlchallenge.com/case-study-5/) | Weekly sales, change analysis and business impact |
| 6 | [Clique Bait](https://8weeksqlchallenge.com/case-study-6/) | Digital events, funnels and campaign performance |
| 7 | [Balanced Tree Clothing Co.](https://8weeksqlchallenge.com/case-study-7/) | Product, transaction and customer analytics |
| 8 | [Fresh Segments](https://8weeksqlchallenge.com/case-study-8/) | Marketing segments, customer mix and trends |
